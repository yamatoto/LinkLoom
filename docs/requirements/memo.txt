  💡 バックエンド構成の選択肢

  選択肢A: React + Supabase（Next.jsなし）

  AI難易度判定や自動収集は以下で実装します：

  1. Supabase Edge Functions（推奨）

  // Supabase Edge Functions（Deno runtime）
  // デプロイ先: Supabaseのサーバー
  // コスト: 無料枠 500K実行/月

  // supabase/functions/analyze-difficulty/index.ts
  import { serve } from "https://deno.land/std@0.168.0/http/server.ts"

  serve(async (req) => {
    const { title, description } = await req.json()

    // OpenAI APIで難易度判定
    const difficulty = await analyzeWithAI(title, description)

    return new Response(JSON.stringify({ difficulty }))
  })

  メリット:
  - バックエンドコード不要（Supabase内で完結）
  - TypeScript/Deno環境
  - 無料枠が大きい

  デメリット:
  - Deno環境（Node.jsと微妙に違う）
  - デバッグが少し面倒

  2. Supabase Database Functions（PostgreSQL）

  -- PostgreSQL関数として実装
  -- 簡単なロジックならこれで十分

  CREATE OR REPLACE FUNCTION auto_set_defaults()
  RETURNS TRIGGER AS $$
  BEGIN
    NEW.created_at = NOW();
    NEW.view_count = 0;
    RETURN NEW;
  END;
  $$ LANGUAGE plpgsql;

  メリット:
  - データベース側で完結
  - 高速

  デメリット:
  - 複雑なロジック（AI呼び出し等）は難しい

  3. クライアント側（React）

  // フロントエンドで実行

  🎯 追加検討すべき必須級ライブラリ

  1. React Hook Form ⭐ 強く推奨

  用途: フォーム管理

  なぜ必須級？
  - 記事登録フォーム、編集フォームが複数ある
  - Zodとの統合が完璧（@hookform/resolvers/zod）
  - パフォーマンス◎（非制御コンポーネント）
  - バリデーションエラー表示が簡単

  使用例:
  import { useForm } from 'react-hook-form'
  import { zodResolver } from '@hookform/resolvers/zod'
  import { z } from 'zod'

  const articleSchema = z.object({
    title: z.string().min(1, '必須です'),
    url: z.string().url('有効なURLを入力してください'),
    tags: z.array(z.string()).min(1),
  })

  const { register, handleSubmit, formState: { errors } } = useForm({
    resolver: zodResolver(articleSchema)
  })

  代替案: なし（React標準のフォーム管理は複雑すぎる）

  ---
  2. date-fns or Day.js 🕐 推奨

  用途: 日付フォーマット

  なぜ必要？
  - 記事の投稿日表示（例: "2025年10月5日", "3日前"）
  - 日本語ロケール対応
  - 軽量（date-fns: tree-shakable, Day.js: 2KB）

  使用例:
  import { format, formatDistanceToNow } from 'date-fns'
  import { ja } from 'date-fns/locale'

  // "2025年10月5日"
  format(new Date(), 'yyyy年MM月dd日', { locale: ja })

  // "3日前"
  formatDistanceToNow(new Date(article.created_at), {
    locale: ja,
    addSuffix: true
  })

  推奨: date-fns（Next.jsと相性◎、tree-shakable）

  ---
  3. clsx + tailwind-merge 🎨 必須

  用途: className管理

  なぜ必須？
  - TailwindのclassNameを条件付きで結合
  - 重複クラスの競合を解決（cnユーティリティ）

  使用例:
  import { clsx } from 'clsx'
  import { twMerge } from 'tailwind-merge'

  export function cn(...inputs: ClassValue[]) {
    return twMerge(clsx(inputs))
  }

  // 使用
  <div className={cn(
    "p-4 rounded",
    isActive && "bg-blue-500",
    "hover:bg-blue-600" // 重複してもマージされる
  )} />

  shadcn/uiのデフォルト: 既に含まれている想定（lib/utils/cn.ts）
