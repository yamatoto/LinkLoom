  📋 初期セットアップでやるべきこと

  npx create-next-app@latest LinkLoom --typescript --tailwind --app --src-dir --import-alias "@/*"

  2. 依存関係インストール

  cd LinkLoom
  npm install react-hook-form @hookform/resolvers zod
  npm install @supabase/supabase-js
  npm install @tanstack/react-query zustand
  npm install dayjs clsx tailwind-merge sonner
  npm install -D vitest @vitest/ui
  npm install -D @playwright/test
  npm install -D prettier eslint-config-prettier

  npx shadcn-ui@latest init

  4. 設定ファイル整備

  - tsconfig.json

  - .env.local.example

  6. Git初期化

  git init

  💡 提案: セットアップをお手伝いしましょうか？

  オプションA: 自動セットアップスクリプト実行

  SuperClaudeの /sc:task を使って、上記をまとめて実行できます：

  /sc:task "Next.js 15プロジェクトの初期セットアップを実行。create-next-app実行、依存関係インストール、shadcn/ui初期化、設定ファイル作成、ディレクトリ構造作成、Git初期化まで完了。"

  オプションB: 手順を一つずつガイド

  一つずつコマンドを確認しながら進めます。

  オプションC: 自分でセットアップ

  セットアップ完了後に機能開発に戻ってきます。

  ---
  🤔 どうしますか？

  1. オプションA: /sc:task で自動セットアップ（推奨・最速）
  2. オプションB: 一つずつガイドしながら進める
  3. オプションC: 自分でセットアップ（後で機能開発に戻る）

  どれが良いですか？
