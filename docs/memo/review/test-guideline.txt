  改善前（現在のセクション9）

  ## 9. 具体的な"型"サンプル（超要約）

    - MSWで`GET /projects`を200/500に切替 → UIの表示・トーストを検証。

  改善後（推奨）

  ## 9. 完全なコード例とパターン

  ### Pattern 1: TanStack Query + UI（成功/失敗）

  \`\`\`typescript
  // tests/unit/components/ProjectList.test.tsx
  import { render, screen, waitFor } from '@testing-library/react'
  import { renderWithProviders } from '@/tests/helpers/renderWithProviders'
  import { server } from '@/tests/mocks/server'
  import { http, HttpResponse } from 'msw'
  import { ProjectList } from '@/components/ProjectList'

  describe('ProjectList', () => {
    it('プロジェクト一覧取得成功時にプロジェクト名を表示', async () => {
      // Given: API成功レスポンス準備
      server.use(
        http.get('/api/projects', () => {
          return HttpResponse.json([
            { id: '1', name: 'Project A' },
            { id: '2', name: 'Project B' }
          ])
        })
      )

      // When: コンポーネントをレンダリング
      renderWithProviders(<ProjectList />)

      // Then: ローディング後にプロジェクト名が表示される
      expect(screen.getByText(/読み込み中/)).toBeInTheDocument()
      await waitFor(() => {
        expect(screen.getByText('Project A')).toBeInTheDocument()
        expect(screen.getByText('Project B')).toBeInTheDocument()
      })
    })

    it('API失敗時にエラートーストを表示', async () => {
      // Given: API失敗レスポンス準備
      server.use(
        http.get('/api/projects', () => {
          return HttpResponse.json(
            { error: 'Internal Server Error' },
            { status: 500 }
          )
        })
      )

      // When: コンポーネントをレンダリング
      renderWithProviders(<ProjectList />)

      // Then: エラーメッセージが表示される
      await waitFor(() => {
        expect(screen.getByText(/プロジェクトの取得に失敗しました/)).toBeInTheDocument()
      })
    })
  })
  \`\`\`

  **キーポイント:**
  - AAA（Arrange/Act/Assert）パターン明確
  - MSWでHTTP層をモック（fetch差し替えではない）
  - `waitFor`で非同期安定化（sleep不使用）
  - 観測可能な結果をアサート（内部実装に依存しない）
