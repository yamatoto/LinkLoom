# 記事編集・削除機能

**何を作るか**: 既存記事を閲覧しながら内容を更新・削除できる詳細ページとフォーム

**なぜ必要か**: 登録済み記事の誤り修正や整理を行い、記事管理を完結させるため

**どこに実装するか**: `src/app/articles/[id]/page.tsx` と関連クライアントコンポーネント

**主要機能**:

- 記事詳細表示（タイトル・URL・説明・登録日時）
- 編集フォーム（初期値適用＋バリデーション＋送信中状態）
- Server Action `updateArticle` による記事更新
- Server Action `deleteArticle` と確認モーダルによる削除
